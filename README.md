# Awesome Fly-Brain Computing [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of open-source projects on *fly-inspired computing* — FlyHash and sparse distributed representations, mushroom-body learning, spiking & neuromorphic models, and fly-brain approaches to trading.

This list is the **computing** companion to the connectome-focused [cobanov/awesome-fly](https://github.com/cobanov/awesome-fly) — it deliberately excludes every repository already listed there, so the two do not overlap.

Auto-curated from the GitHub Search API (20 repositories, newest-first, filtered by stars and topic, deduplicated within this list and against cobanov/awesome-fly). Each section is sorted by stars.

## FlyHash & Sparse Distributed Representations

- [dizcza/EmbedderSDR](https://github.com/dizcza/EmbedderSDR) — Embedder with binary sparse distributed representation. (⭐ 20) `Python`
- [benjamin-asdf/vsa-binary-sparse-distributed-segments-clj](https://github.com/benjamin-asdf/vsa-binary-sparse-distributed-segments-clj) — HDC/VSA: Binary Sparse Distributed Representation with segments (⭐ 6) `Clojure`

## Mushroom-Body Learning

- [BrainsOnBoard/paper_RPEs_in_drosophila_mb](https://github.com/BrainsOnBoard/paper_RPEs_in_drosophila_mb) — Code and data for the manuscript "Learning with reinforcement prediction errors in a model of the Drosophila mushroom body". (⭐ 6) `MATLAB`
- [sngx762/fly-trader](https://github.com/sngx762/fly-trader) — 🪰 Biomimetic trading agent based on Drosophila mushroom body spiking neural network with dopamine RPE learning. Currently supports crypto (BTC/ETH), XAUUSD support in development. (⭐ 3) `Python`

## Spiking & Neuromorphic

- [brian-team/brian2](https://github.com/brian-team/brian2) — Brian is a free, open source simulator for spiking neural networks. (⭐ 1239) `Python`
- [nengo/nengo](https://github.com/nengo/nengo) — A Python library for creating and simulating large-scale brain models (⭐ 949) `Python`
- [BrainCog-X/Brain-Cog](https://github.com/BrainCog-X/Brain-Cog) — Brain-inspired Cognitive Intelligence Engine (BrainCog) is a brain-inspired spiking neural network based platform for Brain-inspired Artificial Intelligence and simulating brains at multiple scales. The long term goal of BrainCog is to provide a comprehensive theory and system to decode the mechanisms and principles of human intelligence and its evolution, and develop artificial brains for brain-inspired conscious living AI in future Human-AI symbiotic Society. (⭐ 655) `Python`
- [genn-team/genn](https://github.com/genn-team/genn) — GeNN is a GPU-enhanced Neuronal Network simulation environment based on code generation for Nvidia CUDA and AMD HIP. (⭐ 283) `C++`
- [SpikeCalls/FlyDrones](https://github.com/SpikeCalls/FlyDrones) — A fruit fly connectome as a drone pilot. Camera -> fly eyes -> spiking brain -> descending neurons -> drone. Live 3D demo in your browser. (⭐ 232) `Python`
- [NACLab/ngc-learn](https://github.com/NACLab/ngc-learn) — NGC-Learn: Computational Neuroscience and NeuroAI in Python (⭐ 210) `Python`
- [fzenke/auryn](https://github.com/fzenke/auryn) — Auryn: A fast simulator for spiking neural networks with synaptic plasticity (⭐ 111) `C++`
- [brian-team/brian2cuda](https://github.com/brian-team/brian2cuda) — A brian2 extension to simulate spiking neural networks on GPUs (⭐ 82) `Python`
- [norse/notebooks](https://github.com/norse/notebooks) — Notebooks illustrating the use of Norse, a library for deep-learning with spiking neural networks. (⭐ 36) `Jupyter Notebook`
- [colinator/spikeflow](https://github.com/colinator/spikeflow) — Python library for easy creation and running of spiking neural networks in tensorflow. (⭐ 33) `Jupyter Notebook`
- [ShahriarRezghi/Spyker](https://github.com/ShahriarRezghi/Spyker) — High-performance Spiking Neural Networks Library Written From Scratch with C++ and Python Interfaces. (⭐ 31) `C++`
- [Neuromorphicism/fly-brain-snntorch](https://github.com/Neuromorphicism/fly-brain-snntorch) — Sparse snnTorch implementation of Fruit Fly (Drosophila Melanogaster) Brain (⭐ 30) `Python`
- [Ibtisam-Mohammad/Fly.exe](https://github.com/Ibtisam-Mohammad/Fly.exe) — Runs the complete released Drosophila male CNS connectome (165,122 neurons, 25.5M edges) inside a physical fly body, in closed loop, on one GPU. (⭐ 21) `Python`
- [suifei/flywire-fly-lab](https://github.com/suifei/flywire-fly-lab) — 把果蝇全脑连接组跑在一台 16GB 笔记本上：接身体、做成浏览器游戏（Running the whole Drosophila brain connectome on a 16 GB laptop, wiring it to a body, shipping it as a browser game ） (⭐ 14) `HTML`
- [Sylviali-Maker/flybrain-sim](https://github.com/Sylviali-Maker/flybrain-sim) — 基于 MaleCNS 果蝇连接组、Brian2 与 FlyGym/MuJoCo 的神经元级脑-身体闭环仿真实验台：支持食物/天敌刺激、166 神经元 raster、教学因果链与虚拟果蝇主视角。 (⭐ 9) `Python`
- [kkokosa/dotFly](https://github.com/kkokosa/dotFly) — Native .NET inference engine for fly-connectome spiking models (MaleCNS, FlyWire) — and an honest demo of what such simulations are (⭐ 8) `C#`
